# Library Management System (C++)

A robust, high-performance desktop application for automating daily library operations — built entirely in C++. This project replaces traditional paper-based registries with a digital, object-oriented architecture, using classes like `Book`, `Member`, and `Transaction` to model real-world library entities.

## Features
- 📚 Add, update, and remove book records
- 🔄 Check-out and return tracking
- 💰 Automated overdue fine calculation
- 👥 Role-based access (Student vs. Librarian) via inheritance
- 💾 Persistent storage using C++ file handling (`fstream`) — no database required
- 🔍 Fast in-memory search and sorting using vectors/linked lists (by ISBN, genre, etc.)
- 🖥️ Lightweight CLI interface — no heavy third-party dependencies

## Tech Highlights
- **Language:** C++ (OOP-based design)
- **Storage:** File-based persistence (text/binary via `fstream`)
- **Data Structures:** Vectors / Linked Lists for dynamic search & sort
- **Design Principles:** Encapsulation, Inheritance, Memory Management

A great foundational project for learning file I/O, OOP principles, and practical database logic in C++.
